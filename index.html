Java · JPA · Hibernate · DAO · MySQL

Registro de personas desde la terminal.

Aplicación de consola que lista, agrega, busca, actualiza y elimina personas en MySQL. El menú no habla con la base de datos: llama a una capa DAO, y Hibernate traduce esos objetos Java en SQL.

  • Java 17
  • Maven
  • JPA 3.1
  • Hibernate 6
  • MySQL

Qué hace

Al ejecutarse se conecta a MySQL en localhost:3306, abre la unidad de persistencia y muestra este menú. La base se llama escuela y la tabla persona guarda id, nombre, edad y correo.

01

Mostrar todas

Lista las personas ordenadas por id.

02

Agregar

Pide nombre, edad y correo, y guarda el registro.

03

Buscar por ID

Localiza una persona o avisa si no existe.

04

Actualizar

Muestra los datos actuales y guarda los nuevos.

05

Eliminar

Borra la persona con el id indicado.

00

Salir

Cierra el menú y la conexión JPA.

Cómo está organizado

Capa Clase Función
Entidad modelo/Persona.java Representa la tabla con @Entity, @Id y @Column.
Contrato DAO dao/PersonaDAO.java Define el CRUD sin decir cómo se guardan los datos.
Implementación dao/impl/PersonaDAOImpl.java Ejecuta el CRUD con EntityManager y transacciones.
Conexión conexion/JPAUtil.java Crea y cierra el EntityManagerFactory hacia MySQL.
Configuración META-INF/persistence.xml Declara la unidad SistemaPersonasPU y a Hibernate como proveedor.
Interfaz prueba/PruebaPersona.java Menú de consola. Es la clase principal de Maven.

Requisitos

  • Java 17
  • Maven
  • MySQL en localhost, puerto 3306
  • Usuario y contraseña en PruebaPersona.java (por defecto root / root)

Cómo ejecutarlo

  1. Enciende MySQL.
  2. Ajusta usuario y contraseña si hace falta.
  3. Desde la carpeta del proyecto corre:
mvn compile exec:java

También se puede abrir como proyecto Maven en NetBeans. Si el usuario de MySQL tiene permisos, Hibernate crea la base escuela y la tabla persona. El script sql/escuela.sql sirve para crearlas a mano.
